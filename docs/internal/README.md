# Internal notes

Plans, diagnoses and reviews written while e2er was built: version plans (v0.5 to v1.0), the M4
run findings, the robustness review, the user-journey notes and design notes. They record why
the code is the way it is, and the code and tests cite them. They are not user documentation and
may describe states of e2er that no longer exist. The user documentation is the
[README](../../README.md) and the other files in [docs/](../).
